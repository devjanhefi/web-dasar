# Belajar Dasar Web Development

📘 Repository ini berisi dokumentasi proses belajar **dasar-dasar Web Development (HTML dan CSS)**. Project ini dibuat sebagai catatan pembelajaran pribadi sekaligus fondasi awal sebelum masuk ke pengembangan web yang lebih kompleks.

Tujuan utama repository ini **bukan membuat aplikasi siap produksi**, melainkan:

* Memahami struktur dasar web
* Mengenal cara kerja HTML dan CSS
* Melatih kebiasaan menulis kode terstruktur

---

## 📂 Struktur Folder

| Folder       | Deskripsi                                                          |
| ------------ | ------------------------------------------------------------------ |
| `html-dasar` | Elemen dasar HTML (heading, paragraf, list, link, image)           |
| `css-dasar`  | Styling dasar (selector, warna, font, box model, layout sederhana) |

---

## 🎯 Tujuan Pembelajaran

Melalui repository ini, saya mempelajari:

* Struktur dokumen HTML yang benar
* Pemisahan concern antara HTML (struktur) dan CSS (tampilan)
* Cara membaca dan menulis kode web yang rapi


---

## 🧠 Catatan

* Kode disusun berdasarkan topik pembelajaran, bukan berdasarkan fitur aplikasi
* Tidak semua file saling terhubung
* Fokus utama adalah **pemahaman konsep**, bukan desain visual
